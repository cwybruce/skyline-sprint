Skyline Sprint is a 2D rooftop runner set in Neon Bay at sunset: sprint across
neon rooftops, jump the gaps between towers, slide under glowing billboards,
grab coins, and outrun the police helicopter as the heat rises. One more
mistake than your hearts allow and you're wiped out — run it back and beat
your best. Built for the make.fun gta6-01 bounty ($1,666).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Space (or tap) to run.

## Controls

- **Space / ↑ / W / tap** — jump (press again mid-air for a double jump)
- **↓ / S** — slide under billboards
- **P / Esc** — pause, **M** — mute
